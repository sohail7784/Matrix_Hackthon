SUBMISSION RULES (MANDATORY)

Your team must submit a ZIP folder containing the following:
📄
1. README.mdProblem statement, solution overview, features, tech stack, and setup/run instructions.
💻
2. SOURCE CODEComplete working code of your project. All files required to run the project.
🖥️
3. PPT/PDF PRESENTATIONProblem → Approach → Solution → Demo → Impact. Clear and well-structured.
🖼️
4. SCREENSHOTS (PNG/JPG)Screenshots of the working project, interface, or output.
📁
5. REQUIRED FILES / ASSETSDataset, configuration files, or any other files required to run the project (if applicable).
▶️
6. RUN INSTRUCTIONSStep-by-step guide to run your project locally.
🔗
7. DEMO / REPOSITORY LINKGitHub link or live demo link (if applicable).
👥
8. TEAM DETAILSTeam name and all member names/IDs clearly mentioned.
⚠️

DISQUALIFICATION CONDITIONS

Any of the following may lead to disqualification:
  • ✕Missing any mandatory file from ZIP.
  • ✕Code doesn't run / crashes during live execution.
  • ✕Submitted project is incomplete or substantially non-functional.
  • ✕Plagiarism / copied project or tutorial solution.
  • ✕Fake or misleading demo / results.
  • ✕Does not address the chosen problem statement.
  • ✕Team / member information is missing or incorrect.
  • ✕Submission after the deadline.
  • ✕Multiple submissions (if not allowed).
  • ✕Judges cannot verify the solution due to missing files or access.
🏆

FINAL SELECTION

Winners will be selected based on the 100-point judging criteria. Team score = average of judges' scores. In case of a tie, the team with higher Execution (Works Live) score wins.
